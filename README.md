# Gitぱっち

Gitを使い始めた学生が、ローカルリポジトリでのコミット活動を楽しく続けるためのCLIアプリです。

登録したGitリポジトリの最新コミットを確認し、新しいコミットがあればペット「ぱっち」に経験値を与えます。Git活動をペットの成長として見える形にすることで、「今日も少しコミットしてみよう」と思えるきっかけを作ります。

## 現在できること

- ペットの状態表示
- ごはんによる満腹度の回復
- なでることによる機嫌の回復
- リポジトリの登録・一覧・編集・削除（削除時は `y` / `n` で確認）
- 報酬済みコミットIDをリポジトリごとに記録し、未報酬コミットだけ固定30XPを付与
- Git活動確認時の連続活動日数・最長記録・称号の表示
- 経験値加算とレベルアップの自動テスト
- `Clock.fixed` と一時Gitリポジトリを使った、日時・実行場所に依存しない自動テスト

## 今後の課題

- ペットとリポジトリ情報のCSV保存・復元
- 検索フォルダ配下からclone済みGitリポジトリを探す機能

現在は状態をメモリ上で保持しているため、終了するとペットと登録リポジトリの情報は失われます。報酬済みコミットIDもメモリ上だけで、CSV保存は未実装です。

GitHub CLI連携やpush回数の集計、ショップ、複数ペットなどはMVPの対象外です。

## 起動方法

Java 21でコンパイル・起動します。

```sh
javac --release 21 -d /tmp/gitpatch-java21 src/*.java
java -cp /tmp/gitpatch-java21 Main
```

機能の自動テストを実行する場合は、次を使います。

```sh
java -cp /tmp/gitpatch-java21 MainTest
```
