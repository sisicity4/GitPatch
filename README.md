# Gitぱっち

Gitを使い始めた学生が、ローカルリポジトリでのコミット活動を楽しく続けるためのCLIアプリです。
登録したGitリポジトリの最新コミットを確認し、新しいコミットがあればペット「ぱっち」に経験値を与えます。Git活動をペットの成長として見える形にすることで、「今日も少しコミットしてみよう」と思えるきっかけを作ります。

## 現在できること

- ペットの状態表示
- ごはんによる満腹度の回復(固定)
- なでることによる機嫌の回復(固定)
- リポジトリの登録・一覧・編集・削除（削除時は `y` / `n` で確認）
- 報酬済みコミットIDをリポジトリごとに記録し、未報酬コミットだけ経験値を付与(30EXP固定)
- Git活動確認時の連続活動日数・最長記録・称号の表示

## CRUD

Create（作成）

- petの初期状態の生成
- 新たなレポジトリの読み込み
- CSVァイルの新規作成

Read（読み取り）

- ユーザ指定gitレポジトリの最終コミットの読み込み
- CSVファイルの読み込み

Update（更新）

- ペット状態(level,exp,hunger,mood)の更新
- 登録レポジトリの更新
- レポジトリのコミットstreakの履歴の更新

Delete（削除）

- gitpatchで登録したgitレポジトリ情報の削除

## 起動方法

Java 21でコンパイル・起動します。

```
javac --release 21 -d /tmp/gitpatch-java21 src/*.java
java -cp /tmp/gitpatch-java21 Main
```
