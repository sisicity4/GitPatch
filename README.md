# Gitぱっち

Gitを使い始めた学生が、ローカルリポジトリでのコミット活動を楽しく続けるためのCLIアプリです。

登録したGitリポジトリの最新コミットを確認し、新しいコミットがあればペット「ぱっち」に経験値を与えます。Git活動をペットの成長として見える形にすることで、「今日も少しコミットしてみよう」と思えるきっかけを作ります。

## 現在できること

- ペットの状態表示
- ごはんによる満腹度の回復
- なでることによる機嫌の回復
- 経験値加算とレベルアップの自動テスト

## MVPで目指すこと

- リポジトリの登録・一覧・編集・削除
- 最新コミットIDの確認と、重複しない経験値付与
- ペットとリポジトリ情報のCSV保存・復元
- 初心者にも分かる入力・エラー案内

GitHub CLI連携やpush回数の集計、ショップ、複数ペットなどはMVPの対象外です。

## 起動方法

Java 21でコンパイル・起動します。

```sh
javac -d bin src/*.java
java -cp bin Main
```

ペット機能の自動テストを実行する場合は、次を使います。

```sh
java -cp bin Main --test
```
